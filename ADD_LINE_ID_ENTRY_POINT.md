# ADD_LINE_ID_ENTRY_POINT.md

## Persona
Database migration engineer with Tkinter UI experience.

## Direct Aim
Add a `parent_line_id` column to the `students` table in `inventory.db` and expose it in the Add Student and Edit Student dialogs on the Students tab.

## Overall Aim
Enable teachers to store parent LINE IDs per student so the Zone B teacher portal can send lesson reports via LINE. This is the missing entry point — without it, parent messages generated by the pipeline have nowhere to look up the LINE ID.
